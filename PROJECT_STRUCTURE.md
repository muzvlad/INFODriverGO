## Подробное описание компонентов

### 📁 backend/ - Модули backend

#### `__init__.py`
- Инициализация пакета backend

#### `main_bot.py`
- **Класс**: `MainBot`
- Основной класс бота, координирует работу всех компонентов
- Содержит методы отправки уведомлений

#### `bot_runner.py`
- **Класс**: `BotRunner`
- Запуск бота с настройкой Application
- Обработка ошибок и совместимости

#### `file_manager.py`
- **Класс**: `FileManager`
- Работа с файлами данных (поздравления, события, свадьбы)
- Загрузка/сохранение данных групп

#### `group_manager.py`
- **Класс**: `GroupManager`
- Управление информацией о группах
- Кэширование названий групп

#### `settings_manager.py`
- **Класс**: `AllSettings`
- Управление настройками всех групп
- Работа с файлами в папке `groups/`

#### `button_handlers.py`
- **Класс**: `ButtonHandlers`
- Обработка нажатий кнопок в Telegram
- Управление настройками через интерфейс

#### `lightweight_scheduler.py`
- **Класс**: `LightweightJobScheduler`
- Облегченный планировщик для Raspberry Pi
- Управление активными заданиями

#### `utils.py`
- **Функции**: `validate_chat_id()`, `get_bot_from_context()`
- Общие утилиты для повторяющихся операций
- Централизованная обработка стандартных задач

#### `scheduler/` - Модуль планировщика уведомлений

##### `__init__.py`
- Инициализация модуля планировщика

##### `main.py`
- **Класс**: `UnifiedJobScheduler`
- Объединение всех миксинов планировщика

##### `job_scheduler.py`
- **Класс**: `JobScheduler`
- Основной планировщик дней рождения
- Настройка ежедневных уведомлений

##### `wedding_scheduler.py`
- **Класс**: `WeddingSchedulerMixin`
- Планировщик свадебных уведомлений

##### `event_scheduler.py`
- **Класс**: `EventSchedulerMixin`
- Планировщик событийных уведомлений
- Поддержка разных типов повторений

##### `scheduler_utils.py`
- **Класс**: `SchedulerUtilsMixin`
- Вспомогательные функции планировщика

#### `command_handlers/` - Модуль обработчиков команд

##### `__init__.py`
- Инициализация модуля команд

##### `base_handler.py`
- **Класс**: `BaseCommandHandler`
- Базовый класс для всех обработчиков

##### `command_handlers.py`
- **Класс**: `CommandHandlers`
- Точка входа для всех команд
- Объединяет все модули команд

##### `user_commands.py`
- **Класс**: `UserCommands`
- Команды для обычных пользователей
- `/start`, `/help`, `/settings`, управление уведомлениями

##### `admin_commands.py`
- **Класс**: `AdminCommands`
- Административные команды
- Статистика, управление ботом

##### `birthday_commands.py`
- **Класс**: `BirthdayCommands`
- Работа с днями рождения
- Добавление, удаление, список

##### `wedding_commands.py`
- **Класс**: `WeddingCommands`
- Работа со свадьбами
- Добавление, удаление, список

##### `event_commands.py`
- **Класс**: `EventCommands`
- Работа с событиями
- Добавление, удаление, список

##### `status_handlers.py`
- **Класс**: `StatusHandlers`
- Обработка статусных команд
- Маршрутизация русских команд

### 📁 groups/ - Настройки групп

Файлы в формате `{chat_id}.json` с настройками каждой группы:
- `chat_name` - название группы
- `notifications_enabled` - включены ли уведомления
- `notification_time` - время уведомлений
- `birthdays` - дни рождения участников
- `weddings` - годовщины свадеб
- `events` - события

## Архитектура

### Принципы дизайна
- **Модульность**: каждый компонент отвечает за свою область
- **Слабая связанность**: компоненты взаимодействуют через интерфейсы
- **Единая точка входа**: `main.py` координирует работу всех модулей
- **Расширяемость**: легко добавлять новые функции
- **Разделение ответственности**: четкое разделение зон ответственности

### Модульная архитектура

Проект следует принципам чистой архитектуры:

1. **Слой представления**: `command_handlers/`, `button_handlers.py`
2. **Слой бизнес-логики**: `main_bot.py`, `settings_manager.py`
3. **Слой данных**: `file_manager.py`, `scheduler/`
4. **Инфраструктура**: `bot_runner.py`, `config.py`

### Поток данных
1. `main.py` инициализирует все компоненты
2. `BotRunner` запускает бота
3. Команды обрабатываются через `CommandHandlers`
4. Кнопки обрабатываются через `ButtonHandlers`
5. Данные управляются через `FileManager`
6. Настройки групп через `SettingsManager`
7. Уведомления через `JobScheduler`

### Совместимость
- Python 3.11+ (рекомендуется)
- Windows/Linux/macOS
- Поддержка Raspberry Pi (через lightweight_scheduler)
