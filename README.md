# Ассистент дней рождения для Telegram

Бот для управления днями рождения, годовщинами свадеб и регулярными событиями в Telegram-группах. Работает через long polling — вебхуки не нужны.

## Возможности

- Дни рождения: добавление, удаление, список, именинники дня и ближайшие
- Годовщины свадеб с отдельными поздравлениями
- Повторяющиеся события (ежедневно, еженедельно, раз в две недели, ежемесячно, одноразово)
- Автоматические уведомления в своё время для каждой группы
- Поздравления выбираются случайно из коллекции шаблонов в `wishes/`
- Настройки и данные хранятся отдельно для каждой группы в `groups/`
- Русскоязычные команды

## Установка

Требуется Python 3.11+.

```bash
git clone https://github.com/muzvlad/INFODriverGO.git
cd INFODriverGO
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

```env
BOT_TOKEN=токен_от_BotFather
TIMEZONE=Europe/Moscow
```

Токен бота выдаёт [@BotFather](https://t.me/BotFather).

## Запуск

```bash
python main.py
```

На Windows можно использовать `start_bot.bat`, он сам активирует venv и проверит зависимости.

## Команды

| Команда | Описание |
|---------|----------|
| `/старт` | Начать работу |
| `/справка` | полный список команд |
| `/добавить Имя ДД.ММ` | добавить день рождения |
| `/список` | все дни рождения группы |
| `/удалить Имя` | удалить день рождения |
| `/сегодня` / `/ближайшие` | именинники сегодня / впереди |
| `/свадьба Имя ДД.ММ`, `/свадьбы`, `/несвадьба Имя` | годовщины свадеб |
| `/событие тип время название`, `/события`, `/несобытие Название` | события |
| `/включить` / `/выключить` / `/статус` | уведомления |
| `/время ЧЧ:ММ` | время ежедневных уведомлений |
| `/настройки` | текущие настройки чата |

Подробные форматы событий — в `/справка`.

## Структура

```
backend/    обработчики команд, планировщик, работа с файлами
groups/     настройки групп (создаются ботом, не коммитятся)
wishes/     шаблоны поздравлений и событий
config.py   загрузка .env и валидация
main.py     точка входа
```

`groups/template.json` показывает формат файла группы. Реальные файлы с личными данными исключены через `.gitignore`.

## Безопасность

`.env` и содержимое `groups/*.json` не попадают в репозиторий. Для публичного.use клона скопируйте `.env.example` в `.env` и укажите свой токен.
