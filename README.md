# Ассистент дней рождения для Telegram

Умный помощник для управления и отслеживания дней рождения в Telegram группах.

## Основные возможности

- Управление днями рождения: добавление, удаление, просмотр списка
- Автоматические уведомления в удобное время для каждой группы
- Персональная база данных для каждой Telegram-группы
- Случайные поздравления из коллекции более 20 вариантов
- Управление сообщениями для администратора проекта
- Работа через лонг поллинг (без необходимости вебхуков)
- Современная модульная архитектура для простой поддержки и развития

## Архитектура проекта

### Модульная структура

Проект использует модульную архитектуру для лучшей поддержки и расширяемости:

```
backend/command_handlers/
├── base_handler.py         # Базовый класс обработчиков
├── user_commands.py        # Команды для обычных пользователей
├── admin_commands.py       # Административные команды
├── birthday_commands.py    # Работа с днями рождения
└── status_handlers.py      # Обработка статуса
```

### Преимущества модульной архитектуры

- Четкое разделение ответственности - каждый модуль выполняет свою задачу
- Простота поддержки и поиска ошибок
- Повышенная производительность за счет загрузки только необходимых компонентов
- Удобство тестирования отдельных модулей
